# AI 与资源管理

## AI 服务

进入 **AI → 服务商管理**，配置上游协议和连接信息。

![AI 服务商管理截图](/guide/admin/ai-providers.jpg)

服务商表单包含服务商标识、显示名称、协议类型、Base URL、API Key、测试模型、优先级、超时、描述与启用状态。API Key 只填写密钥本体，不要包含 `Bearer`。

推荐配置顺序：

1. 新增服务商并完成连接测试。
2. 同步或创建模型，填写对外模型名、显示名称、上下文窗口和输入/输出积分价格。
3. 创建用户 API Key，限制所属用户、允许模型和过期时间。
4. 使用“模型预设”配置系统提示词、温度、Token 与上下文限制。
5. 在“模型测试”验证输出，再观察调用日志与余额。

> **注意：成本与密钥**
>
> 修改模型价格会影响后续计费；停用服务商或模型会影响已有 API Key。任何页面截图、日志和导出文件都不应包含完整上游密钥或用户密钥。

## 资源

**资源** 模块包含 Cloudflare R2、本地资源和回收站。资源列表可以查看文件名、路径、类型、大小、创建人和时间，也可以进入详情预览来源与元数据。

- 普通删除会把资源移入回收站，并可能影响关联的网站、应用、壁纸或站点图标。
- 回收站支持恢复；超过 60 天的数据会自动清除。
- 回收站“删除”会同步删除对象存储文件，且无法恢复。

删除前先通过资源路径确认引用位置，并在 Web、Admin 两个域名验证对应 `/static/` URL。部署映射说明见 [部署与 Nginx 配置](/guide/deployment)。
