# Admin 端概览

Admin 端用于配置 Search Next 实例。本地开发地址为 `http://localhost:8133/`；生产环境请使用管理后台独立域名，并限制非管理员访问。

登录后，左侧菜单会按当前用户的角色和接口权限过滤。拥有完整权限的账号会看到系统、用户、资源、AI 和新标签页五个模块。

![管理后台首页截图](/guide/admin/overview.jpg)

## 模块导航

| 模块 | 主要功能 |
| --- | --- |
| 系统 | 角色、权限、版本、通知、协议与隐私、站点与注册设置 |
| 用户 | 用户列表、状态、角色和用户详情 |
| 资源 | Cloudflare R2、本地资源与回收站 |
| AI | 服务商、模型、API Key、日志、余额、预设和模型测试 |
| 新标签页 | 搜索引擎、网站、应用、壁纸、主题、桌面配置与云同步 |

## 通用操作模式

多数列表页都提供新增、筛选、刷新、导入/导出或批量操作。表格右侧的“操作”列包含启用/禁用、修改、详情和删除。

> **权限与数据安全**
>
> - 先配置权限，再把权限授予角色，最后给用户分配角色。
> - 禁用内容通常会影响 Web 端展示；删除前先确认是否有桌面或备份引用。
> - API Key、Turnstile Secret Key 和备份文件属于敏感数据，不要放入截图或公开文档。

建议先阅读 [搜索与网站内容](/admin/content)，再配置 [应用、壁纸与桌面](/admin/apps-desktop)。
