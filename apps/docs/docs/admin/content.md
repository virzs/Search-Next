# 搜索与网站内容

## 搜索引擎

进入 **新标签页 → 搜索引擎**，可以新增、导入、导出、启用、禁用、修改或删除搜索引擎。

![搜索引擎管理截图](/guide/admin/search-engine.jpg)

新增或编辑时重点检查：

- 搜索 URL 必须包含 `{keyword}`，系统会替换为编码后的搜索词。
- 建议词 JSONP URL 需要同时包含 `{keyword}` 和 `{jsonp}`。
- JSONP 处理代码可以返回数组，也可以使用 `(resp) => [...]` 或 `(resp, kw) => [...]`。
- 保存前使用“测试搜索”和“获取 JSONP”核对结果。
- 禁用后，Web 端不再把该引擎作为可选项。

## 网站

进入 **新标签页 → 网站**，依次维护分类、标签、合集和网站。

![网站管理截图](/guide/admin/website.jpg)

### 推荐顺序

1. 创建分类，用于商店筛选和运营分组。
2. 创建标签，用于补充搜索关键词和内容属性。
3. 新增网站，填写名称、描述、URL、图标、分类和标签。
4. 需要运营专题时，把网站加入合集并设置展示顺序。
5. 确认“启用”和“公开”状态后，再到 Web 端验证。

“启用”控制内容是否可用，“公开”控制内容是否向普通用户展示。修改或取消公开前，应先确认是否已经被桌面、合集或备份引用。

> **批量迁移**
>
> 搜索引擎和网站列表支持导入/导出。导入前先导出当前数据作为回滚点，并先在测试环境检查重复项、分类和图标资源。
