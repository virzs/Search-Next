# 常见问题

## Web 端显示“应用不可用”

先在 Admin 端确认应用和对应版本处于启用状态，再检查应用入口、`/static/` 资源和 `/api/tabs/desktop/.../runtime/...` 接口。部署环境可参考 [部署与 Nginx 配置](/guide/deployment)。

## 桌面无法继续添加页面、配置或云备份

管理员可在 **新标签页 → 桌面 → 用户限制** 配置默认上限，并按角色覆盖。数值范围为 1–100；修改后重新打开 Web 端确认新限制已加载。

## 云备份提示已达到版本上限

在 **设置 → 备份与恢复** 选择覆盖一个已有版本，或联系管理员调整当前角色的最大云备份数。覆盖前建议先导出 `.snbak` 本地备份。

## 导入备份后当前设置消失

导入会覆盖当前本地设置，这是预期行为。导入前应先导出当前数据；如果已有导出文件，可以再次导入该文件恢复。

## 管理后台没有某个菜单

菜单按角色权限动态过滤。请检查用户角色是否包含该页面对应的接口权限；修改后退出并重新登录验证。不要为了显示菜单直接授予全部高风险权限。

## 表格显示“暂无数据”

确认当前实例、筛选条件和账号权限正确，然后点击刷新。新实例需要先建立分类、角色或服务商等基础数据，再创建引用它们的内容。

## 刷新深层页面返回 404

Web 与 Admin 都是 SPA。Nginx 必须包含：

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

完整示例见 [部署与 Nginx 配置](/guide/deployment)。
