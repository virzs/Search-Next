# 统一搜索

统一搜索把网页搜索、站内网站、应用和设置入口合并在一个面板中。可以直接单击顶部搜索框，也可以使用界面显示的键盘快捷键呼出。

![统一搜索与 @ 命令截图](/guide/web/search-commands.jpg)

## 基本流程

1. 输入关键字。
2. 在搜索框下方切换搜索引擎；当前环境提供必应、百度、谷歌和夸克。
3. 使用方向键选择结果，按 `Enter` 打开；按 `Esc` 关闭面板。
4. 最近打开的网页搜索、网站、应用、页面和设置会进入搜索历史。

## @ 命令

| 命令 | 搜索范围 | 示例 |
| --- | --- | --- |
| `@all` | 网页、网站、应用、设置 | `@all ai` |
| `@ws` | 搜索引擎与建议词 | `@ws Search Next` |
| `@site` | 站内网站 | `@site 知乎` |
| `@app` | 应用 | `@app 时钟` |
| `@setting` | 设置项 | `@setting 主题` |

只输入 `@` 或点击“@命令”会显示完整命令列表。命令与关键字之间保留一个空格，结果更容易匹配。

## 搜索偏好

在 **设置 → 搜索** 中可以控制桌面搜索框是否显示、是否启用 Spotlight 风格快捷键，以及快捷键组合。若快捷键与浏览器或操作系统冲突，请在这里更换。
