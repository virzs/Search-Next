# 桌面与应用

桌面用于组织网站、应用和小组件。不同项目虽然都能放在桌面上，但运行方式不同：网站打开外部链接，应用在独立窗口中运行，小组件直接在桌面展示内容。

## 常用操作

- **打开**：单击网站、应用或 Dock 图标。
- **移动**：拖动桌面项目到目标位置；位置变更会保存在当前浏览器的数据中。
- **跨页整理**：桌面达到当前页面容量后可使用其他页面；最大页面数由管理员按默认值或角色限制。
- **移除**：右键桌面应用并选择“移除应用”。确认框会区分“只移除实例”和“同时删除应用数据”。
- **保留数据**：应用仍有其他桌面实例时，删除共享数据会影响所有实例，操作前请核对提示。

> **注意：应用不可用**
>
> 当应用被管理员停用、下架或资源无法加载时，桌面会显示“不可用”或“正在验证应用状态”。这时应先确认网络与 `/static/`、`/api/` 配置；若应用已停用，可从桌面移除并等待管理员恢复。

## 小组件

小组件通过应用商店的 **小组件** 分类添加。支持多个尺寸的组件会在添加前要求选择尺寸；同一组件可以添加多个实例。

## 数据保存范围

| 数据 | 游客账号 | 登录账号 |
| --- | --- | --- |
| 桌面布局 | 当前浏览器 | 当前浏览器，可通过备份恢复 |
| 应用私有数据 | 当前浏览器 | 当前浏览器，可包含在备份中 |
| 云备份 | 不可用 | 可用，版本数由管理员限制 |

需要安装新项目时，请阅读 [应用商店](/web/store)；需要导出或恢复布局时，请阅读 [账号与备份](/web/account-backup)。
