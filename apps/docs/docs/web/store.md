# 应用商店

应用商店用于发现并添加网站、应用和小组件。打开 Dock 中的 **应用商店** 后，可以使用左侧分类或搜索框缩小范围。

![应用商店截图](/guide/web/store.jpg)

## 三类项目

| 类型 | 添加后的行为 | 适用场景 |
| --- | --- | --- |
| 网站 | 在浏览器中打开目标网址 | 文档、工具、社区和常用链接 |
| 应用 | 在 Search Next 独立窗口运行 | 待办、时钟、计算器等完整功能 |
| 小组件 | 直接显示在桌面 | 持续查看信息或进行轻量操作 |

## 添加项目

1. 从左侧选择 **网站**、**应用** 或 **小组件**。
2. 可以浏览推荐、全部、分类或合集，也可以直接搜索名称。
3. 点击卡片查看详情；点击“获取”或“添加到桌面”。
4. 小组件或多尺寸应用需要选择尺寸。
5. 返回桌面确认图标或小组件已经出现。

网站页右上角的 **自定义** 可以添加常用网址。开发者模式启用后，商店会额外显示 **开发者** 入口，用于测试自定义应用和本地 ESM 入口。

## 移除与数据

右键桌面应用并选择“移除应用”。默认只移除当前实例并保留应用数据；只有确认不再需要数据时，才勾选“同时删除应用数据”。

> **已安装但打不开**
>
> 先检查应用是否被管理员启用，再检查应用版本入口和静态资源是否可访问。部署环境可参考 [部署与 Nginx 配置](/guide/deployment)。
