# Web 端快速开始

Web 端是 Search Next 的日常使用入口。本地开发地址为 `http://localhost:8132/`；生产环境请以实际部署域名为准。

## 第一次打开

首次注册、登录，或服务条款与隐私政策更新后，系统会要求阅读最新版本。可以切换两个页签查看全文；确认前不会继续刚才的登录或注册操作。

![首次使用时的协议与隐私提示截图](/guide/web/first-use.jpg)

> **账号模式**
>
> - **游客账号**：桌面、设置和应用数据只保存在当前浏览器。
> - **登录账号**：可以使用云备份和跨设备恢复；具体上限由管理员配置。

## 认识桌面

![Search Next Web 端桌面截图](/guide/web/desktop.jpg)

| 区域 | 功能 |
| --- | --- |
| 顶部搜索框 | 搜索网页、站内网站、应用和设置；点击 `@命令` 查看限定搜索语法 |
| 桌面图标 | 打开网站、文件夹或应用；图标可拖动调整位置 |
| 小组件 | 在桌面直接展示待办、时钟、计算器等轻量信息或操作 |
| Dock | 打开账号、个性化、应用商店和设置，也会保留最近使用的应用 |
| 右上角 | 查看通知，或前往 GitHub 提交反馈 |

## 建议的首次配置

1. 打开 **账号**，登录或确认继续使用游客账号。
2. 打开 **应用商店**，把常用网站、应用和小组件添加到桌面。
3. 打开 **个性化**，选择主题与壁纸。
4. 打开 **设置 → 搜索**，确认桌面搜索框和快捷键偏好。
5. 登录账号后打开 **设置 → 备份与恢复**，创建第一个备份。

下一步可继续阅读 [桌面与应用](/web/desktop)，或直接了解 [统一搜索](/web/search)。
