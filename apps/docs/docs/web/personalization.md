# 个性化

Dock 中的 **个性化** 集中管理主题、壁纸和用户创建的方案。主题影响窗口、Dock、菜单和图标；壁纸只改变桌面背景。

![个性化中心截图](/guide/web/personalization.jpg)

## 应用主题

1. 进入 **主题**，按分类浏览。
2. 单击主题卡片进入预览详情。
3. 核对浅色与深色效果后，选择“应用到桌面”。

## 选择壁纸

壁纸页提供四个入口：首页、渐变、图片和网页壁纸。单击壁纸可查看效果并应用到当前桌面。

- **渐变壁纸**：使用颜色与渐变参数绘制，不依赖外部图片。
- **图片壁纸**：从上传资源或图片链接加载。
- **网页壁纸**：由应用运行接口提供动态背景；不可用时会恢复默认背景。

## “我的”

“我的”用于管理自定义主题与壁纸：

- 创建主题时分别配置浅色、深色背景与界面配色。
- 添加壁纸时可创建渐变或填写图片链接。
- “保存并应用”会立即参与桌面渲染。
- 自定义方案默认保存在本地；更换浏览器前应先创建备份。

> **注意：删除自定义主题**
>
> 删除后不可恢复；如果删除的是当前主题，桌面会切回默认主题。
