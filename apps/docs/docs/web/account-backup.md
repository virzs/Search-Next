# 账号与备份

## 登录账号

打开 Dock 中的 **账号**，选择“登录或注册”。登录表单要求邮箱、密码，并在提交前确认服务条款与隐私政策。

![用户端登录窗口截图](/guide/web/account-login.jpg)

登录成功后，账号窗口会显示邮箱与加入时间；账号设置中可以修改公开用户名、密码或删除账号。

![登录后的账号窗口截图](/guide/web/account.jpg)

> **注册限制**
>
> 管理员可以关闭注册，或要求邀请码、邮箱验证码和 Cloudflare Turnstile。页面实际出现的字段以当前实例配置为准。

## 设置中心

![设置中心截图](/guide/web/settings.jpg)

设置分为账号、个性化、搜索、语言、备份与恢复、关于和开发者。开发者模式只影响本地应用调试入口，不会自动授予管理后台权限。

## 本地备份与恢复

进入 **设置 → 备份与恢复**：

1. 先查看“当前数据占用”，确认桌面、设置和应用私有数据的大小。
2. 点击“导出”，保存 `.snbak` 文件。
3. 需要恢复时点击“导入”并选择备份文件。
4. 导入完成后检查桌面布局、应用和设置。

> **危险：导入会覆盖当前数据**
>
> 导入前先导出当前数据。备份文件应只保存在可信位置，不要公开上传包含账号或应用数据的备份。

## 云备份

![备份与恢复页面截图](/guide/web/backup.jpg)

登录后可以上传云备份。未达到版本上限时会创建新版本；达到上限后，需要选择并覆盖已有版本。版本数和存储限制由管理后台的 **新标签页 → 桌面 → 用户限制** 配置。
